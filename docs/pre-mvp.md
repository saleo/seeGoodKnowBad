Pre-MVP修订: 强制保留「见人好/见我好」双通道核心灵魂，牺牲部分交互精致度换取极速实现

最后更新: 2026-04-16

📦 Pre-MVP：3天极速版 (第0阶段)

🎯 目标

72小时内交付可运行的最小版本，无后端、无AI、无社区，但必须保留"见好=见人好+见我好"的产品灵魂，验证用户对双通道记录方式的接受度。

🚫 暂不实现 (Cut Scope)

• ❌ 登录/注册/云同步 (纯本地)

• ❌ AI 镜灵/摘要/分析

• ❌ 社区/互动/送光

• ❌ 心镜算法/成就/光阶

• ❌ 心理安全筛查 (本地运行风险可控)

• ❌ 复杂的动效与弹窗

✅ Pre-MVP 功能清单 (3天完成)

1. 单页应用架构 (1天)

• 一个HTML页面，无路由

• 纯前端 (Vue/React单文件或原生JS)

• 数据持久化：微信小程序 Storage

• 无网络请求

2. ⭐ 核心：双通道记录器 (1.5天)

• 交互简化方案：用分段控件(Segmented Control)替代复杂弹窗，一步到位选择类型。
<!-- UI 伪代码 -->
<输入框 placeholder="记录具体内容...">

<segmented-control>
  [ 🙌 见人好 ]   <!-- 选中态底色橙 -->
  [ 🌟 见我好 ]   <!-- 选中态底色金 -->
  [ 🌊 知非  ]    <!-- 选中态底色蓝 -->
</segmented-control>

<button> 保存记录 </button>


• 逻辑：保存时记录 type + subtype，为后续算法留伏笔。

• 发布反馈：简单Toast提示，无粒子动画。

3. 时间轴视图 (1天)

• 记录倒序排列

• 左侧色块+Emoji 三重编码，直观区分：

  • 🟠 🙌 见人好 (橙)

  • 🟡 🌟 见我好 (金)

  • 🔵 🧠 知非  (蓝)

• 显示相对时间

4. 极简设置 (0.5天)

• "清除所有记录"按钮 (触发confirm)

• "导出JSON"链接 (下载备份)
