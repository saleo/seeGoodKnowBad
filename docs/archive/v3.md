一、项目概述 (继承自v2.1，无变更)

1.1 产品定位

「见好知非」是一款基于双向觉察理念的心灵成长社区工具。区别于传统单向记录的日记，产品通过引导用户每日记录“见好”（既见他人之好，亦见自我之好）与“知非”（觉察言行偏差），辅以AI洞察与温暖社交，帮助用户在记录中对抗消极偏见，养成平衡的思维习惯，实现可持续的心灵成长。

1.2 核心价值主张

- •**对个人**：通过每日记录，培养觉察力与反思习惯，实现持续自我成长
- •**对关系**：记录与见证亲友的善行，增进情感连接，传递温暖
- •**对社区**：提供去竞争化的社区环境，通过“共鸣”而非“点赞”建立连接。构建一个真诚、温暖、鼓励成长的互助社区


1.3 目标用户画像 (不变)

- •希望培养积极习惯、追求自我成长的人群
- •重视家庭关系、人际关系，愿意记录和分享美好时刻的人群
- •需要自我反思、情绪管理支持的人群
- •寻找有深度、有温度的社交体验的人群

七、核心技术修订 (v3.0 重点注入)

7.1 「知非」心理安全三层防护网 (全新)

层级 机制 执行点 处置方式

L1 客户端轻筛 本地关键词匹配 用户输入时 提示"内容敏感，建议联系专业帮助"，不阻断输入但警示

L2 服务端硬拦截 高危词库+语义 提交时 阻断入库，返回"为安全无法保存" + 紧急热线

L3 AI主动监测 情绪强度评分 周期扫描 镜灵定向关怀，必要时人工介入

📞 紧急资源：产品底部常驻"获取专业帮助"入口，链接触达国家级热线。

7.2 心镜亮度算法重构 (废除惩罚逻辑)

❌ 废弃v2.1惩罚逻辑：× Consistency (断签归零)

✅ v3.0 温和算法：

Brightness_t = \alpha \cdot \sum_{i=1}^{t} e^{-\lambda(t-i)} \cdot R_i + \beta \cdot C_t

• R_i：记录质量（见好=1.0，知非+修正=0.8…）

• C_t：连续天数（仅正向加分，断签不减分）

• 核心哲学：接纳暂停，拒绝制造“因漏记而自我否定”的焦虑。

7.3 AI Proxy 安全架构 (生产级加固)


Client → [Auth] → [Input Sanitizer] → [Safety Filter] → [LLM Proxy] → API
                                  ↓                              ↓
                           [Blocklist拒止]                [Fallback降级]
                                  ↓                              ↓
                           [规则响应] ←----------------- [缓存模板]


防御新增：
1.  防注入：清洗 """、Ignore previous 等Prompt攻击向量。
2.  硬阻断：命中高危词库直接拒止，不透传LLM。
3.  降级兜底：LLM异常时返回预置关怀话术，不暴露系统错误。
