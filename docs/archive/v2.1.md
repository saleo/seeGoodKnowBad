# 见好知非 产品设计文档 (v2.1)

## 一、项目概述

### 1.1 产品定位

见好知非是一个帮助用户见证美好、觉察不足的心灵成长工具。用户通过每日记录"见人好"、"见我好"和"知非"，形成持续成长的轨迹，支持本地存储和云端同步。

### 1.2 核心价值主张

- **对个人**：通过每日记录，培养觉察力与反思习惯，实现持续自我成长
- **对记录**：支持本地存储和云端同步，数据安全可靠

### 1.3 目标用户

- 希望培养积极习惯、追求自我成长的人群
- 需要自我反思、情绪管理支持的人群

#### 4.2.2 核心功能点

1. **记录输入区**：支持多行文本输入，实时反馈
2. **类型选择**：三段式分段控件，分别对应三种记录类型
3. **成长流时间线**：所有记录按时间倒序显示
4. **视觉区分**：
   - 见人好：左侧晨曦金（#FFB300）竖条
   - 见我好：左侧金色（#F1C40F）竖条
   - 知非：左侧静夜蓝（#0D47A1）竖条
5. **本地+云端双存储**：记录自动保存到本地，登录后同步到云端

#### 4.2.3 交互细节

- **保存记录**：点击保存按钮，显示成功提示
- **同步提示**：登录后显示云端同步状态
- **单条分享**：点击每条记录的分享按钮可分享
- **清空确认**：清空前弹出确认对话框
- **导出数据**：将所有记录复制到剪贴板

## 五、核心交互流程

### 5.1 新用户引导流程

```markdown
启动小程序
  → 展示登录页（心形Logo + 品牌文案）
  → 点击微信一键登录
  → 完善个人资料（可选）
  → 进入记录页，显示空状态引导
  → 引导发布第一条记录
```

### 5.2 每日记录流程

```markdown
进入记录页
  → 选择记录类型（见人好/见我好/知非）
  → 输入记录内容
  → 点击保存
  → 显示成功提示
  → 记录自动保存到本地
  → 若已登录，自动同步到云端
  → 记录显示在成长流顶部
```

### 5.3 数据同步流程

```markdown
登录后
  → 自动从云端拉取历史记录
  → 与本地记录合并（去重）
  → 显示同步成功提示
  → 新记录自动同步到云端
```

## 九、技术实现要点

### 9.1 前端架构

```
技术栈：
- 框架：uni-app 3.x + Vue 3 Composition API
- 编译目标：mp-weixin（微信小程序）
- 状态管理：Pinia
- 本地存储：utils/storage.js
- 云服务：微信云开发

性能优化：
1. 本地优先，云端同步为兜底
2. 列表虚拟滚动（长列表优化）
3. 合理的数据缓存策略
4. 分页加载（预留）
```

### 9.2 后端架构（微信云开发）

```
服务架构：
- 云函数：处理登录、同步记录
- 数据库：存储用户数据、记录数据
- 存储：用户头像等文件（预留）

数据库设计：
- users 表：用户信息
- records 表：记录数据
```

### 9.3 关键功能实现

1. **本地存储**：使用 uni.setStorage/uni.getStorage
2. **云端同步**：登录后自动同步，新记录自动上传
3. **数据合并**：云端和本地记录智能合并，避免重复
4. **离线可用**：未登录时完全可用，数据保存在本地
