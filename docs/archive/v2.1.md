# 见好知非 产品设计文档

## 一、项目概述

### 1.1 产品定位

见好知非是一个帮助用户见证美好、觉知不足的心灵成长工具。用户通过每日记录"知好"（善行）和"知非"（自省），形成持续成长的轨迹，并通过社交互动获得支持与鼓励。

### 1.2 核心价值主张

- •**对个人**：通过每日记录，培养觉察力与反思习惯，实现持续自我成长
- •**对关系**：记录与见证亲友的善行，增进情感连接，传递温暖
- •**对社区**：构建一个真诚、温暖、鼓励成长的互助社区

### 1.3 目标用户

- •希望培养积极习惯、追求自我成长的人群
- •重视家庭关系、人际关系，愿意记录和分享美好时刻的人群
- •需要自我反思、情绪管理支持的人群
- •寻找有深度、有温度的社交体验的人群

## 二、产品名称与品牌体系

### 2.1 产品名称

**见好知非**

### 2.2 命名寓意

- •**心镜**：以心为镜，映照真实自我
- •**365**：每日记录，全年陪伴，形成成长轨迹
- •整体寓意：通过每日的记录与反思，让内心如明镜般澄澈，照亮成长之路

### 2.3 品牌口号体系

\| 功能口号 | 见好成光，知非而进​ | 用于产品核心功能引导 |

### 2.4 Logo设计

**动态心镜日历概念**：

- •**形状**：心形轮廓，内部巧妙融入数字"365"
- •**材质**：镜面质感，反射微光
- •**色彩**：晨曦金（#FFB300）渐变
- •**动效**：启动时心镜从磨砂质感逐渐变为明镜，记录后亮度变化

## 五、核心交互流程

### 5.1 新用户引导流程

```markdown
启动小程序
  → 展示启动页（见好知非，照亮每一天）
  → 首次使用引导
  → 微信一键登录
  → 完善个人资料（可选）
  → 进入首页，显示空状态引导
  → 引导发布第一条记录
```

### 5.2 每日记录流程

```markdown
进入首页
  → 点击顶部"记录"按钮
  → 选择记录类型（见好/知非）
  → 输入记录内容
  → 选择话题标签
  → 设置可见范围
  → 点击发布
  → 返回首页，新记录显示在顶部
  *
  → 心镜亮度增加
  → 连续记录天数更新
```

### 5.3 社交互动流程

```markdown
浏览时间线
  → 看到感兴趣记录
  → 点击点赞按钮
  → 动画反馈，点赞数+1
  → 或点击评论按钮
  → 输入评论内容
  → 发布评论
  → 记录作者收到评论通知
```

### 5.4 隐私管理流程

```markdown
查看自己的记录
  → 点击记录右上角"···"
  → 选择"修改可见范围"
  → 选择新范围（公开/好友可见/仅自己）
  → 确认修改
  → 记录可见范围图标更新
  → 如果改为仅自己，原有互动隐藏
```

## 七、动效设计规范

4. 4.**成就解锁**：徽章弹出 + 金色粒子特效

### 7.3 页面过渡

1. 1.**水平切换**：首页、消息、个人中心之间
2. 2.**垂直弹出**：记录页面、详情页面
3. 3.**渐入渐出**：弹窗、浮层
4. 4.**共享元素过渡**：图片预览、用户头像

## 八、数据结构设计

### 8.1 核心数据模型

```javascript
// 用户模型
User {
  userId: String,           // 用户ID
  avatar: String,          // 头像URL
  nickname: String,        // 昵称
  bio: String,             // 个人简介
  joinDate: Date,          // 加入日期
  stats: {                 // 统计数据
    streakDays: Number,    // 连续记录天数
    lightCount: Number,    // 见好总数
    reflectCount: Number,  // 知非总数
    likeReceived: Number,  // 获赞总数
    commentReceived: Number, // 获评论总数
    mirrorBrightness: Number // 心镜亮度 0-100
  },
  settings: {              // 用户设置
    defaultVisibility: String, // 默认可见范围
    commentPermission: String, // 评论权限
    notificationSettings: Object // 通知设置
  }
}

// 记录模型
Record {
  recordId: String,        // 记录ID
  userId: String,          // 作者ID
  type: String,           // 类型: 'light' | 'reflect'
  content: String,        // 内容
  images: Array<String>,  // 图片URL数组
  topics: Array<String>,  // 话题标签
  visibility: String,     // 可见范围: 'public' | 'friends' | 'private'
  location: Object,       // 位置信息
  createdAt: Date,        // 创建时间
  updatedAt: Date,        // 更新时间
  likes: Array<String>,   // 点赞用户ID数组
  comments: Array<Comment>, // 评论数组
  meta: {                 // 元数据
    wordCount: Number,    // 字数
    hasImage: Boolean,    // 是否有图片
    isEdited: Boolean     // 是否编辑过
  }
}

// 评论模型
Comment {
  commentId: String,      // 评论ID
  userId: String,         // 评论者ID
  content: String,        // 评论内容
  createdAt: Date,        // 评论时间
  replyTo: String,        // 回复的评论ID（可选）
  likes: Array<String>    // 点赞用户ID数组
}

// 消息模型
Message {
  messageId: String,      // 消息ID
  type: String,          // 类型: 'comment' | 'like' | 'follow' | 'system'
  fromUser: User,        // 发送者
  targetRecord: Object,  // 目标记录（可选）
  content: String,       // 消息内容
  createdAt: Date,       // 创建时间
  read: Boolean,         // 是否已读
  meta: Object           // 元数据
}
```
